## INTERNET

Интернет - глобальная сеть взаимосвязанных компьютерных сетей, которые обмениваются данными по сетевым протоколам TCP/IP. Отличие всемирной паутины от интернета, что всемирная паутина, это как библиотека с книгами, только вместо книг веб страницы, веб каталоги и гиперссылки.
Пользователь ввел адрес сайта в адресную строку браузера, сначала DNS помогает определить IP адрес данного сайта, потом отправляет запрос, после того как запрос обработан, приходит ответ, браузер обрабатывает HTML, при необходимости загружает CSS, JavaScript и другие ресурсы, а затем отображает страницу.

## DNS

DNS - это распределённая система, в которой разные DNS-серверы отвечают за разные части пространства доменных имён.

Доменное имя и IP-адрес очень тесно связаны между собой, доменные имена, как раз таки используются для удобства пользователей, чтобы не запоминать полные IP-адреса.

DNS-кеш используется для того,чтобы запоминать к каким доменным именам мы обращались и какие у них IP-адреса, это полезно тем,что не нужно будет снова искать IP адрес доменного имени. DNS-записи имеют определенный TTL (Time To Live) и определяет срок действия кешированной DNS-записи.

## HTTP/HTTPS

HTTP (HyperText Transfer Protocol) - это протокол, который определяет правила обмена запросами и ответами сервера и клиента.

HTTPS - это защищенный HTTP с использованием TLS шифрования.

Главное отличие, это дополнительное шифрование, оно помогает пользователям проверить подлинность сервера для указанного домена,а также сохранить безопасность данных, которые они передают, пароли, логины, карты, почту, мобильный телефон и т.д.

HTTPS не гарантирует, что сайт безопасен, а также не гарантирует, безопасное хранение данных на сайте.

## FRONTEND / BACKEND

Frontend - часть приложения, с которой взаимодействует пользователь

Backend - серверная часть приложения, которая обрабатывает запросы, содержит бизнес-логику и взаимодействует с хранилищами данных.

Пример на практике:
Интернет сайт магазина DNS, пользователь видит каталог, кнопки добавить в корзину, цену, название, описание - это все Frontend часть приложения. А Backend хранит данные об этом пользователе, какие покупки он ранее совершал, при добавлении в корзину, добавляет данные о товаре, который выбрал пользователь.

## HTML / CSS / JAVASCRIPT

HTML - определяет структуру сайта и смысл содержимого страницы.

CSS - отвечает за размещение и оформление элементов на странице.

JavaScript - делает страницу динамичной.

Пример на практике:

Интернет сайт магазина DNS. HTML определяет структуру содержимого страницы, текст, поля для ввода. То, как видит это пользователь, различные цвета, удобное расположение - это CSS. Обработать нажатие, изменить содержимое страницы,отправить запрос - это JavaScript.
