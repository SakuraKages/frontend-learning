## INTERNET

Интернет - глобальная сеть взаимосвязанных компьютерных сетей, которые обмениваются данными по сетевым протоколам TCP/IP. Отличие всемирной паутины от интернета, что всемирная паутина, это как библиотека с книгами, только вместо книг веб страницы, веб каталоги и гиперссылки.
Пользователь ввел адрес сайта в адресную строку браузера, сначала DNS помогает определить IP адрес данного сайта, потом отправляет запрос, после того как запрос обработан, приходит ответ, браузер обрабатывает HTML, при необходимости загружает CSS, JavaScript и другие ресурсы, а затем отображает страницу.

## DNS

DNS - это справочная книга интернета. В нем хранятся все IP-адреса сайтов. Он нужен для более удобного использования и помогает людям не запоминать какой IP-адрес, к какому сайту относится. Доменное имя и IP-адрес очень тесно связаны между собой, доменные имена, как раз таки используются для удобства людьми, чтобы не запоминать полные IP-адреса. DNS-кеш используется для того,чтобы запоминать к каким доменным именам мы обращались и какие у них IP-адреса, это полезно тем,что не нужно будет снова искать IP адрес доменного имени.
