# Frontend Learning

This project is required for the final assessment in Module 1. It demonstrates all my knowledge and skills in using Git and GitHub.

## The topics studied

- The basics of the internet and the web.
- PowerShell and the beginning of Git.
- Basic Git.
- Branches and merges.
- Conflicts and GitHub.

## Basic Git commands

- `git init`
- `git status`, `git add`, `git commit`, `git log`, `git diff`, `git diff --staged`
- `git branch`, `git merge`, `git switch`
- `git push`, `git remote`, `git pull`, `git fetch`

## Git workflow

- Creating a project
- Initializing the project
- Creating .gitignore rules
- Creating and filling out README.md
- Creating a feature branch and committing changes.
- Creating and filling out web-basics.md
- Pushing local commits to the remote repository.
- Creating a Pull Request and merging the feature branch.
